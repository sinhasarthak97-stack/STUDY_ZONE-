# Study Zone

Study tracker, goals, focus timer with XP, notes, an AI tutor (AI Guru), AI practice questions, and the **Science 3D Lab** (Resources tab): 118-element periodic table, 3D atoms, 240+ molecules, and an AI-powered compound search.

## Put it online with GitHub Pages (free)
1. Create an account at github.com and verify your email.
2. Click **+ > New repository**. Name it `study-zone`, choose **Public**, click **Create repository**.
3. Click **Add file > Upload files**. Upload all six files from this folder (index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png, README.md). Keep them in the main folder, not in a subfolder. Click **Commit changes**.
4. Open **Settings > Pages**. Under Build and deployment choose **Deploy from a branch**, branch **main**, folder **/ (root)**, then **Save**.
5. Wait 1 to 3 minutes. Your app is at `https://YOUR-USERNAME.github.io/study-zone/`.
6. On your phone open the link, then Chrome menu > **Install app** (or Add to Home screen). Safari: Share > **Add to Home Screen**.
7. To update later, upload the new files with the same names and commit.

## Turn on AI on GitHub
Inside Claude the AI works automatically. On GitHub there is no built-in AI, so:
1. Get an API key at console.anthropic.com (Settings > API keys). Usage is billed to your account.
2. In the app open **Settings > AI key** and paste it. It is saved only in your own browser and is never included in backups.
3. Do not enter your key on a phone or computer you share with other people.

## Notes
- Compound Search uses PubChem (NIH) and needs internet. The built-in molecules work offline.
- Progress is saved only in your own browser. Use Settings > Save backup now and then.
